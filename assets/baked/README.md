# Baked presentation resources

These are the exact payloads previously embedded in checked-in C++ arrays:
wallpapers, UI and notes artwork, shader archives, title presentation and Minos/
GoatUp 2 artwork. They preserve the shipped bytes, not original authoring files.
`MANIFEST.json` records each consumer, symbol, size and SHA-256 digest.

The normal CMake build verifies every payload and generates byte includes under
the build directory. No generated byte arrays are maintained in source control.
Game resources use the same build-time embedding principle through their own
game archive bundler; game/runtime ownership stays separate from presentation.

After intentionally replacing a baked resource, refresh the recorded hashes:

```sh
python tools/embed_baked_assets.py --manifest assets/baked/MANIFEST.json --refresh
```

Then rebuild normally. Changing a resource does not rewrite unrelated generated
includes. Source images, fonts and scene documents retain their own attribution
and licensing; extracting an existing payload does not establish new provenance.

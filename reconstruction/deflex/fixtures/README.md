# Original-execution fixtures

Capture headers identify unpublished extraction harnesses, including
`tools/deflex/original_exec.py`. These are provenance identifiers, not
regeneration commands supplied by this source package. The committed records
are inputs to the checks and do not require the capture harness at test time.
Original-execution records and source-level rule tests provide different evidence;
neither should be silently replaced with output from the C++ implementation.
